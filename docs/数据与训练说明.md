# 数据与训练说明

## 1. 数据来源

训练图像来自 **ISIC（International Skin Imaging Collaboration）皮肤镜图像库**，共 616 张，按 6 个类别存放在 `病变照片/<类别>/` 目录下：

| 类别 | 目录名 | 张数 |
|---|---|---|
| 基底细胞癌 | `basal_cell_carcinoma` | 321 |
| 黑色素瘤 | `melanoma` | 87 |
| 光化性角化病 | `actinic_keratosis` | 80 |
| 痣 | `nevus` | 71 |
| 皮肤纤维瘤 | `dermatofibroma` | 42 |
| 血管病变 | `vascular_lesion` | 15 |

> 图像因体积（约 162 MB）与授权原因**不随仓库分发**；请自行从 [ISIC Archive](https://www.isic-archive.com/) 获取同名图像。

## 2. 从图片到 YOLO 数据集

本项目的检测标注为"整幅图中病灶的包围框"。若你只有分类目录，可用如下方式生成一个弱标注数据集（整图即目标框）：

```python
# 生成 datasets/{images,labels}/{train,val} 的 YOLO 格式（整图作为单目标框）
from pathlib import Path
import random, shutil

SRC = Path("病变照片")
DST = Path("datasets")
CLASSES = ["vascular_lesion", "basal_cell_carcinoma", "actinic_keratosis",
           "dermatofibroma", "melanoma", "nevus"]

random.seed(42)
for split in ("train", "val"):
    (DST / "images" / split).mkdir(parents=True, exist_ok=True)
    (DST / "labels" / split).mkdir(parents=True, exist_ok=True)

for idx, cls in enumerate(CLASSES):
    imgs = sorted((SRC / cls).glob("*.jpg"))
    random.shuffle(imgs)
    n_val = max(1, int(len(imgs) * 0.2))
    for i, p in enumerate(imgs):
        split = "val" if i < n_val else "train"
        shutil.copy(p, DST / "images" / split / p.name)
        # YOLO: class cx cy w h（归一化）；整图作为框
        (DST / "labels" / split / (p.stem + ".txt")).write_text(f"{idx} 0.5 0.5 1.0 1.0\n")

(DST / "data.yaml").write_text(
    "path: datasets\ntrain: images/train\nval: images/val\n"
    f"nc: {len(CLASSES)}\nnames: {CLASSES}\n"
)
```

## 3. 训练

```bash
yolo detect train model=yolov8m.pt data=datasets/data.yaml \
     imgsz=640 epochs=150 batch=10 optimizer=AdamW lr0=0.001
```

本项目自带的 `models/best.pt` 即按上述规模训练（Ultralytics 8.3.63，150 epochs）。训练日志中的 `args.data` 已抹去原始本机路径。

## 4. 评估

```bash
yolo detect val model=models/best.pt data=datasets/data.yaml
```

## 5. 已知局限

- 图像量小（616 张）、类别不均衡（`vascular_lesion` 仅 15 张）；
- 标注为整图弱标注时，模型倾向输出覆盖整幅图的框，细粒度定位能力有限；
- 仅覆盖 6 类，未包含 ISIC 全部病变类型；
- 结果**不能作为医疗诊断依据**。
